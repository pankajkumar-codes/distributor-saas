**Material objection (1)**

**M-1 (Major): L-2 portal test upload on a live GSTIN (L-2, section 10a week 3, section 13).** The BRD says "test GSTR-1 upload with Pankaj's own GSTIN" and sets no safeguards. A CA would ask three things:
- Which period is it? A test return built from masked or synthetic data uploaded against a real, live GSTIN risks polluting a real GSTR-1 draft, or being filed by accident.
- Does it clash with NF-14, which allows only masked synthetic fixtures?
- Who cleans up afterwards?

Concrete change to L-2: "Upload only into a period already filed or not yet open for the test GSTIN, or a dedicated test GSTIN if one is lawfully available. Never press Generate Summary, Submit or File. Reset or delete the draft afterwards and record it in DECISIONS. A CA confirms the procedure first (CA to confirm whether portal drafts can be safely reset)."
